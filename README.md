Klantenbeheer Dashboard

### Beschrijving van het project

Voor het keuzedeel Frontend Development ontwikkel ik een responsive
webapplicatie voor het beheren van klantgegevens.

De gebruiker kan klanten bekijken, zoeken, toevoegen en wijzigen.

De frontend wordt ontwikkeld met HTML, CSS, JavaScript en Bootstrap.
De applicatie moet goed werken op mobiel, tablet en desktop.

### Reden waarom ik dit project wil maken

Ik wil met dit project leren hoe ik een professionele en responsive
frontend kan ontwikkelen met Bootstrap.

Ik wil daarnaast meer ervaring opdoen met het structureren van pagina's,
werken met Bootstrap-componenten, Git, GitHub, testen en SEO.

### Randvoorwaarden

- De website moet responsive zijn.
- De website moet werken op mobiel, tablet en desktop.
- Bootstrap wordt gebruikt als frontend-framework.
